# Pullet Player

Official Windows x64 downloads for Pullet Player.

## Download

Download **PulletPlayer-v1-win-x64.zip** from [the latest release](https://github.com/XMJGame/PulletPlayer-Releases/releases/latest), extract the complete archive, and run **PulletPlayer.exe**. Keep all accompanying files and folders. GitHub's automatic Source code archives are not application installers.

本仓库提供 Pullet Player Windows x64 软件发行包，不包含产品源码。从最新发布页下载 ZIP，完整解压后运行 PulletPlayer.exe，保留全部随附文件和文件夹。Source code 压缩包不是软件安装包。
